# Provenance and attribution

RaptorShield is an independently modified fork of the **FoxyShield** Chrome extension.

| Detail                                       | Known provenance                                                                                     |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Base project name                            | FoxyShield                                                                                           |
| Base package version                         | 1.0.0, as declared in the supplied manifest                                                          |
| Associated branding                          | FoxyNet, as present in the supplied description and interface                                        |
| Starting material                            | Packaged Manifest V3 extension: JavaScript bundles, HTML, CSS, icons, fonts, and third-party notices |
| Upstream repository                          | Not supplied or verified                                                                             |
| Original application author/copyright notice | Not supplied in the application files inspected                                                      |
| Original application license                 | Not supplied                                                                                         |
| Original Git history/build project           | Not supplied                                                                                         |

Credit for inherited implementation belongs to the original FoxyShield contributors. FoxyNet is recorded here as the branding present in the package, without asserting a separately verified author identity. This fork does not claim authorship of the inherited code or endorsement by the original project.

RaptorShield changes include provider-independent activation, exit-IP inspection, manual reputation-report links, protection/exception fixes, English/LTR localization, and F-22-inspired branding. See [CHANGELOG.md](CHANGELOG.md).

The original `THIRD_PARTY_NOTICES.txt` is retained unchanged, including its FoxyShield heading and component attribution. Bundled third-party material includes Vazirmatn, Twemoji country-flag assets, and Lucide icon material. Retained legacy assets may not all be used by the current interface.

No replacement application license is asserted by this notice. The verified upstream project URL and applicable application license remain to be recorded before publication terms can be described accurately.
